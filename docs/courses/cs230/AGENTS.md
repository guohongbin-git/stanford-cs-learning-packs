
# CS230 Course Agent Contract

## 1. Purpose

本文件定义CS230 Autumn 2025课程包中Agent如何使用课程语义。目标是辅助学习和复盘，不替代Stanford课程材料。

## 2. Version Boundary

版本锁定Autumn 2025。所有内容标记TEACHING_RECONSTRUCTION，表示教学重构而非官方原文。

## 3. Read Order

建议先读取course_ir理解周结构，再读取concepts建立概念关系，最后使用HTML交互视图。

## 4. Evidence Semantics

概念解释来自公开课程主题重组，需要区分事实、教学解释和学习建议。

## 5. Agent Use Contract

Agent可以解释概念、生成练习和检查覆盖，但不得声称代表课程教师。

## 6. 适用范围

适用于CS230深度学习学习辅助、知识复习和项目讨论。

## 7. 禁用场景

禁止把课程包作为官方认证、考试答案来源或替代原始课程资料。

## 8. Concept Usage

概念节点用于建立学习地图，每个节点需要结合周次、关系和失败条件理解。

## 9. 双视图

Human视图强调学习路径，Agent视图强调结构化JSON检查和概念调用。

## 10. Capability Rule

Agent输出必须引用课程包中的证据字段，不生成无法追溯的课程结论。

## 11. Skill Formation

学习目标应通过解释、实验、错误分析和项目复盘形成能力。

## 12. Escalation

遇到课程外内容，应明确边界并建议查阅原始资料。

## 13. Update Rule

新版本更新需要修改版本号并重新生成校验清单。

## 14. Maintenance Contract

维护者需保证JSON、HTML内嵌数据和manifest哈希保持一致。
