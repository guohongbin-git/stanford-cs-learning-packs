## Seminar 型课程 Schema 差异（CS25）

CS25 是研讨会（seminar）而非 lecture 课程，因此其 `course_ir.json` 使用 `themes`（主题聚类）而非 `weeks`（教学周），且**不挂载逐模块 quiz / agent 契约**——研讨会的"掌握"体现在对 talk 的理解与讨论，而非通关式小测。Agent 消费 CS25 时应按 talk 级证据（`talks[]`，含 speaker/edition/theme/title_source）工作，不要假设存在周级 quiz。
