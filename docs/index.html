每个包含什么

文件用途读者
*_interactive_*.html单文件交互课程：周导航、概念抽屉、Human/Agent 双视图、小测与进度人
course_ir.json课程结构：周次、目标、失败模式、小测、Agent 契约、讲次证据Agent
concepts.jsoncanonical 概念库：定义 / 为何重要 / 失效条件 / 例子 / 关系 / 周次人 + Agent
AGENTS.md使用规则：版本边界、证据语义、能力判定、升级条件Agent
package_manifest.json全文件 bytes + sha256（可校验）机器

证据与诚实边界

每个包标注素材绑定：active_recent（2023 年后的官方公开播放列表）或 archive_official（官方历史最佳版本）。讲座/talk 条目区分 official: true（逐字官方标题）与 official: false（主题派生标签）。概念状态统一 TEACHING_RECONSTRUCTION：教学重构，不是 Stanford 逐字讲义，无官方隶属关系。

校验自己的副本

python3 tools/verify_pack.py docs/courses/cs336

检查 manifest 的 bytes/sha256、HTML 内嵌 JSON 与独立文件是否逐字段一致、概念字段完整性、周↔概念双向一致、关系目标可解析、模板句骨架命中数。
